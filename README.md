# Learn to Surf Website

This is a simple, modern website to help beginners learn how to surf. It covers the basics, step-by-step instructions, safety tips, and frequently asked questions.

## Features
- Clean, responsive design
- Step-by-step surfing guide
- Embedded beginner video
- Surfing tips and FAQ section

## How to Use
1. Open `index.html` in your web browser.
2. Explore the sections to learn about surfing basics, tips, and FAQs.
3. Click the "Watch Beginner Video" button to view a helpful video.

## File Structure
- `index.html` — Main website page
- `style.css` — Styles for the website
- `script.js` — JavaScript for interactive elements
- `README.md` — Project overview and instructions
